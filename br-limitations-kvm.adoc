= NetApp Backup and Recovery針對 KVM 工作負載的已知限制
:hardbreaks:

:nofooter:

:imagesdir: ./media/


[role="lead"]
查看 NetApp Backup and Recovery 中 KVM 工作負載的目前限制。

以下不支援的動作和組態適用於 NetApp Backup and Recovery 中的 KVM 工作負載：



[[unsupported-actions]]
== 不支援的操作

不支援下列動作：

* 在 NetApp Console 本機部署的備份與還原預覽版本中，僅支援將備份至物件儲存的 ONTAP S3 和 StorageGRID 目標。此預覽版本不支援備份歸檔。
* 克隆、掛載或卸載虛擬機
* 保護儲存在 SAN 上的虛擬機
* 保護應用程式
* 建立使用者定義的備份（僅支援從NetApp Console啟動的備份）




[[unsupported-configurations]]
== 不支援的配置

不支援以下配置：

* 基於角色的存取控制 (RBAC)
* 直接連接到 KVM 主機的磁碟
* 跨多個 NFS 掛載點或共享的磁碟
* RAW磁碟格式
* NetFS 以外的儲存池類型（僅支援 NetFS）




[[troubleshooting-notes]]
== 故障排除說明

使用 KVM 工作負載搭配 NetApp Backup and Recovery 時，請注意以下事項。

* 如果受保護的虛擬機器中未執行 QEMU Guest Agent，則備份可能會失敗。為避免此問題，請確保 `qemu-guest-agent`精靈已在虛擬機器上執行，再啟動備份。
