= 使用NetApp Backup and RecoveryKVM 工作負載
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
將內部部署 ONTAP 系統中的 KVM 保護群組備份至 Amazon Web Services、Azure NetApp Files 或 StorageGRID。當您備份保護群組時，NetApp Backup and Recovery 會備份該群組中的虛擬機器和儲存資源池，並將備份儲存在公有雲或私有雲帳戶的物件存放區中。


NOTE: 若要執行排程備份，請建立治理備份與還原作業的原則。請參閱 link:br-use-policies-kvm-create.html["建立 KVM 保護原則"] 以取得相關說明。

* 建立保護群組，以管理一組資源的備份與還原作業。如需詳細資訊，請參閱 link:br-use-kvm-protection-groups.html["在 NetApp Backup and Recovery 中管理 KVM 保護群組"]。

== 立即使用按需備份來備份保護群組

如果您即將進行變更，並希望先取得最新備份，請立即執行隨需備份。

*所需 NetApp Console 角色* Backup and Recovery 超級管理員或 Backup and Recovery 備份管理員角色 https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["了解所有服務的NetApp Console存取角色"^]。

.步驟
. 從NetApp Console選單中，選擇「保護」>「備份和復原」。
. 在 KVM 圖塊中，選擇 *發現和管理*。
. 選擇*庫存*。
. 選擇工作負載以檢視保護詳細資訊。
. 選擇“操作”圖標image:../media/icon-action.png["操作選項"]> *查看詳情*。
. 選擇「保護群組」、「資料存放區」或「虛擬機器」標籤。
. 選擇要備份的保護組。
. 選擇“操作”圖標image:../media/icon-action.png["操作選項"]> *立即備份*。
+

NOTE: 應用於備份的策略與指派給保護組的策略相同。

. 選擇計劃層級。
. 選擇*備份*。
