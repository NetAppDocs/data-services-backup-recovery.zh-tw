= 使用 NetApp Backup and Recovery 的 Kubernetes 保護工作流程
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
使用 NetApp Backup and Recovery，透過單一介面探索、管理和保護 Kubernetes 叢集和應用程式。

下圖展示了 Kubernetes 備份與恢復的元件和基本架構，以及如何將資料複本儲存在不同的位置：

image:../media/backup-recovery-architecture-diagram.png["Kubernetes 工作負載備份與復原架構圖"]

NetApp Backup and Recovery為管理 Kubernetes 工作負載提供了以下優點：

* 用於保護跨多個 Kubernetes 叢集（包括容器和虛擬機器）的應用程式的單一控制平面。
* 與 NetApp SnapMirror 的原生整合可支援備份與還原工作流程的儲存設備卸載。
* Kubernetes 應用程式的永久增量備份，轉換為更低的復原點目標 (RPO) 和復原時間目標 (RTO)。


您可以對 Kubernetes 工作負載執行下列任務：

* link:br-start-discover-kubernetes.html["發現 Kubernetes 工作負載"]。
* link:br-use-manage-kubernetes-clusters.html["在 NetApp Backup and Recovery 中管理 Kubernetes 叢集"]。
* link:br-use-protect-kubernetes-applications.html["在 NetApp Backup and Recovery 中新增和保護 Kubernetes 應用程式"]。
* link:br-use-manage-kubernetes-applications.html["在 NetApp Backup and Recovery 中管理 Kubernetes 應用程式"]。
* link:br-use-restore-kubernetes-applications.html["恢復 Kubernetes 應用程式"]。
