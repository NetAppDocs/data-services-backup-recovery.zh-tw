= 在 NetApp Backup and Recovery 中建立 Microsoft SQL Server 保護報告
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
在 NetApp Backup and Recovery 中建立 Microsoft SQL Server 工作負載的報告，以審查備份狀態和詳細資訊，包括成功和失敗的備份計數、備份類型、儲存系統和時間戳記。



[[create-a-protection-report]]
== 建立保護報告

*必要的 NetApp Console 角色* 儲存檢視器、備份與還原超級管理員、備份與還原備份管理員、備份與還原還原管理員、備份與還原複製管理員。如果您要保護儲存在 Cloud Volumes ONTAP 叢集上的資料，則還需要 Cloud Volumes ONTAP 管理員角色。了解 link:reference-roles.html["備份和恢復角色和權限"]。 https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["了解所有服務的NetApp Console存取角色"^]。

.步驟
. 從 NetApp Backup and Recovery 選單中，選取 * 報告 *。
. 選擇*建立報告*。
. 輸入報告範圍詳細資料：
+
** *報告名稱*：輸入報告的唯一名稱。
** *報表類型*：選擇您想要按帳戶還是按工作量（Microsoft SQL Server）報表。
** *選擇主機*：如果您按工作負載選擇，請選擇要為其產生報告的主機。
** *選擇內容*：選擇報告是否包含所有備份的摘要或每個備份的詳細資訊。  （如果您選擇“按帳戶”）


. 輸入報告範圍：選擇報告是否包含過去一天、過去 7 天、過去 30 天、過去一個季度或過去一年的資料。
. 輸入報告傳送詳細資料：如果您希望透過電子郵件傳送報告，請選擇 *Send report using email*。輸入您希望接收報告的電子郵件地址。
+
在「設定」頁面設定電子郵件通知。有關設定電子郵件通知的詳細資訊，請參閱 link:br-start-configure.html["配置設定"]。
