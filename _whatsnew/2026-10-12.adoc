[[hyper-v-workloads-enhancements]]
=== Hyper-V 工作負載增強功能

在此版本中、Hyper-V 工作負載引入了以下增強功能：

* *NetApp MetroCluster 支援*：NetApp Backup and Recovery 現在可讓您保護由 NetApp MetroCluster 鏡像的 Hyper-V 虛擬機器。
* *SAN 虛擬機器跨磁碟保護*：對於 CIFS 和 SAN 配置，您現在可以保護保護群組中每個虛擬機器所連接的每個磁碟。這包括分佈在多個 ONTAP 磁碟區或 ONTAP 儲存設備系統上的檔案（跨磁碟）以及僅限於單一位置的檔案。


有關保護 Hyper-V 工作負載的詳細資訊，請參閱 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-hyperv-protect-overview.html["了解如何使用 NetApp Backup and Recovery 保護 Hyper-V 工作負載"]。



[[oracle-database-workloads-enhancement]]
=== Oracle 資料庫工作負載增強

在此版本中、Oracle Database 工作負載引進下列增強功能：

*自動歸檔日誌管理*：在資料庫還原和 Clone 作業期間，NetApp Backup and Recovery 會自動發現並掛載所需的歸檔日誌，然後在作業完成後將其卸載。支援主要、次要和物件儲存日誌來源。

有關保護 Oracle Database 工作負載的詳細資訊，請參閱 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-oracle-protect-overview.html["了解如何使用 NetApp Backup and Recovery 保護 Oracle 資料庫工作負載"]。



[[microsoft-sql-server-workloads-enhancement]]
=== Microsoft SQL Server 工作負載增強

在此版本中，Microsoft SQL Server 工作負載引入了以下增強功能：

*授權變更*：使用磁碟到磁碟或磁碟到磁碟連出架構的備份不再收費。收費僅適用於備份至物件儲存，包括使用 3-2-1 或磁碟到物件儲存架構的備份。

如需保護 Microsoft SQL Server 工作負載的詳細資訊，請參閱 https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-mssql-protect-overview.html["了解如何使用 NetApp Backup and Recovery 保護 Microsoft SQL Server 工作負載"]。
