= 使用 NetApp Backup and Recovery 保護 VMware 工作負載
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
使用 NetApp Backup and Recovery 來保護 VMware 虛擬機器和資料存放區。您可以建立快速、極具空間效率、損毀狀況一致且 VM 一致的備份，將其儲存在支援的備份目標上，並將 VMware 工作負載還原至內部部署的 VMware 主機。


NOTE: 此版本的NetApp Backup and Recovery僅支援 VMware vCenter，且無法發現vVols或vVols上的 VM。

使用 NetApp Backup and Recovery 實作 3-2-1 策略，在 2 個不同的儲存設備系統中保留 3 份來源資料複本，並在雲端保留 1 份複本。3-2-1 方法的優點包括：

* 多個資料副本可防止內部和外部網路安全威脅。
* 如果一種媒體發生故障，使用不同類型的媒體可以幫助您恢復。
* 您可以快速從本機複本還原，如果本機複本損壞，則可以使用異地複本。


您可以使用NetApp Backup and Recovery執行與 VMware 工作負載相關的下列任務：

* link:br-use-vmware-protection-groups.html["為 VMware 工作負載建立和管理保護群組"]
* link:br-use-vmware-backup.html["備份 VMware 工作負載"]
* link:br-use-vmware-restore.html["復原 VMware 工作負載"]
