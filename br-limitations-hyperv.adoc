== 不支援的操作

NetApp Backup and Recovery 不支援對 Hyper-V 工作負載執行這些動作：

* 在 NetApp Console 本機部署的備份與還原預覽版本中，僅支援將備份至物件儲存的 ONTAP S3 和 StorageGRID 目標。此預覽版本不支援備份歸檔。
* NetApp Backup and Recovery 目前不支援保護託管在 FlexGroup 磁碟區上的 Hyper-V LUN。
* 您無法使用來自多個 Hyper-V 主機的虛擬機器建立資源群組。
* 無論 Hyper-V 中的「處理器相容性」設定為何，您都無法在具有不同 CPU 廠商的系統之間（Intel 到 AMD 或反之亦然）還原 VM 或 VM 資料。此設定僅支援同一廠商不同世代之間的相容性（例如，Intel 到 Intel 或 AMD 到 AMD）。
