= 使用 NetApp Backup and Recovery 保護 Oracle 資料庫工作負載
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
使用 NetApp 備份與還原功能，透過快速、極具空間效率、損毀狀況一致和資料庫一致性的備份與還原，保護 Oracle 資料庫工作負載和日誌。您可以將工作負載備份到 AWS S3、StorageGRID、Azure Blob 或 ONTAP S3，並將備份還原至本機 Oracle 主機。

使用 NetApp Backup and Recovery 實作 3-2-1 保護策略，即在兩個不同的儲存設備系統上保留三份來源資料複本，並在雲端保留一份複本。3-2-1 方法的優點包括：

* 多個資料副本可防止內部和外部網路安全威脅。
* 如果一種媒體失效，其他類型的媒體可以幫助您恢復。
* 您可以從現場副本快速恢復，如果現場副本受到損害，則可以使用異地副本。




[[oracle-data-guard-support]]
== Oracle Data Guard 支援

NetApp Backup and Recovery 可以保護具有單一執行個體主資料庫和一個處於掛載狀態之實體備用資料庫的 Oracle Data Guard 組態。
