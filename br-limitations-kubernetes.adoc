[[limitation-in-the-backup-and-recovery-preview-for-netapp-console-local-deployment]]
== NetApp Console 本地部署的 Backup and Recovery 預覽版限制

在 NetApp Console 本機部署的備份與還原預覽版本中，僅支援將備份至物件儲存的 ONTAP S3 和 StorageGRID 目標。此預覽版本不支援備份歸檔。



[[changing-the-protection-policy-for-an-application]]
== 變更應用程式的保護原則

如果變更應用程式的保護原則以使用不同的儲存桶或次要複寫目標，則保護可能會失敗。

*解決方法*：刪除該應用程式，然後重新新增。



[[3-2-1-protection-policy-configuration-limitation]]
== 3-2-1 保護原則組態限制

如果您建立 3-2-1 保護原則，將物件儲存備份與複寫到次要儲存設備分開排程，則保護可能會停滯。

*解決方法*：移除應用程式並重新新增，然後使用不同的保護原則加以保護。
