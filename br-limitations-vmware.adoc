= VMware 工作負載在 NetApp Backup and Recovery 中的已知限制
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
在使用 NetApp Backup and Recovery 處理 VMware 工作負載之前，請先查看這些限制。

NetApp Backup and Recovery 不支援對 VMware 工作負載執行下列操作：

* 在 NetApp Console 本機部署的備份與還原預覽版本中，僅支援將備份至物件儲存的 ONTAP S3 和 StorageGRID 目標。此預覽版本不支援備份歸檔。
* vVol 支持
* 電子郵件集成
* 基於角色的存取控制 (RBAC) 支持
