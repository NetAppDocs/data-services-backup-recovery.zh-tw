= Oracle 資料庫工作負載的 NetApp Backup and Recovery 已知限制
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
查看 NetApp Backup and Recovery 中 Oracle 資料庫工作負載的目前限制和不支援的動作。

在 NetApp Backup and Recovery 預覽版本中，以下動作不支援 Oracle 資料庫工作負載：

* 在 NetApp Console 本機部署的備份與還原預覽版本中，僅支援將備份至物件儲存的 ONTAP S3 和 StorageGRID 目標。此預覽版本不支援備份歸檔。
* 離線備份
