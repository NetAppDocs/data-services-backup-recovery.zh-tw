= KVM 保護工作流程與 NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
使用 NetApp Backup and Recovery 保護您代管的 KVM 虛擬機器和儲存資源池。此服務提供快速、極具空間效率、損毀狀況一致且 VM 一致的備份與還原作業。

您的 KVM 主機和虛擬機器必須由 Apache CloudStack 等平台進行代管，然後才能使用 NetApp Backup and Recovery 加以保護。

使用NetApp Backup and Recovery實作 3-2-1 保護策略，其中您在 2 個不同的儲存系統上擁有 3 個來源資料副本，並在雲端中擁有 1 個副本。3-2-1 方法的優點包括：

* 多個資料副本可防止內部和外部網路安全威脅。
* 使用不同類型的媒體有助於在一種媒體發生故障時進行還原。
* 您可以從現場副本快速恢復，如果現場副本受到損害，則可以使用異地副本。


您可以使用 NetApp Backup and Recovery 對 KVM 工作負載執行下列任務：

* link:br-start-discover-kvm.html["發現 KVM 工作負載"]
* link:br-use-kvm-protection-groups.html["為 KVM 工作負載建立和管理保護群組"]
* link:br-use-kvm-backup.html["備份 KVM 工作負載"]
* link:br-use-kvm-restore.html["恢復 KVM 工作負載"]
